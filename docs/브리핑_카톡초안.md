# 장용민 대표님 1차 시안 브리핑 — 카톡 초안

> 07 단계에서 실제 화면에 맞게 클로드가 다듬습니다. 캡처는 docs/briefing/날짜/ 폴더.

---

대표님 안녕하세요! 「나만의 운세」 1차 시안 공유드립니다 😊

주신 도사·운세보감 앱과 캐릭터 시안을 바탕으로 이렇게 잡았습니다.

1️⃣ 전체 톤
- 밝은 아이보리 바탕에 깔끔하게, 어두운 색은 유료 카드에만 써서 무겁지 않게 했습니다.
- 40~60대 분들 보시기 편하게 본문 글씨를 크게 했고, 설정에서 "크게·아주 크게"로 더 키울 수 있습니다.

2️⃣ 무료 / 유료 카드
- 무료(오늘의 운세·띠별·이번 주·MBTI) = 흰색 일반 카드
- 유료(정통사주·궁합·신년운세) = 금색 테두리 + 프리미엄 배지가 반짝이는 레어 카드

3️⃣ 캐릭터
- 천궁도령: 정통사주·재물·직장·신년운세 안내 (점잖은 말투)
- 월하선녀: 오늘의 운세·애정·궁합·띠별 안내 (다정한 말투)

4️⃣ 흐름
- 무료: 첫 화면에 결제 권유 없이 오늘의 운세 → 총운·한 줄 → 재물·애정·직장·건강
- 유료: 도령/선녀와 상담 → 풀이 선택 → 결제 → 앱 안에서 바로 풀이 확인·저장·공유

📎 첨부: 전체 화면 합본 / 무료 흐름 / 유료 흐름 / 디자인 포인트

아래 몇 가지만 정해주시면 바로 반영하겠습니다.
① 가격 — 월 구독료, 정통사주·궁합·신년운세 단건 가격 (지금은 예시 가격으로 넣어뒀습니다)
② 프리미엄 구독 혜택 — 광고 제거 + 이번 달 운세 + 분야 심화 + 단건 할인 구성 괜찮으실까요?
③ 부적 — 하루 1장 무료(광고 시청) + 프리미엄 무제한으로 할까요?
④ 도메인·앱 이름 주소(패키지명) — 원하시는 도메인 있으시면 알려주세요

결제·스토어 연동은 사업자 나오시면 Play Console·PG 준비해 주시는 대로 바로 붙이겠습니다.
편하게 수정 의견 주세요. 감사합니다!
