# 양도 체크리스트 — 나만의 운세 (H COMPANY → 장용민 대표님)

> 모든 계정·키는 **대표님 명의**로 만들고, 개발사(H COMPANY)는 작업 기간 동안 **멤버로 초대**받아 설정만 합니다. 양도가 끝나면 개발사 접근을 해제합니다.

## 0. 양도 당일 순서 (2026-10-22 기준 현재 상태)

| 순서 | 할 일 | 누가 | 상태 |
|---|---|---|---|
| 1 | 대표님 Railway 가입 + 카드 등록 (**Hobby 월 $5 이상 — 무료 요금제로는 프로젝트를 받을 수 없음**) | 대표님 | ☐ |
| 2 | 개발사 Railway 프로젝트 naman-unse → Settings → Members 에서 대표님 이메일 초대 → 대표님 옆 ⋯ → **Transfer Ownership** → 대표님 메일에서 24시간 안에 수락 (주소·DB·변수 전부 그대로, 중단 없음) | 개발사 → 대표님 | ☐ |
| 3 | 납품본 소스를 대표님 GitHub 비공개 저장소에 올림 (`npm run export:delivery` 결과 폴더 = 내부 문서 뺀 깨끗한 사본) | 개발사 | ☐ |
| 4 | 관리자 화면 → 관리자 계정: 대표님 이메일 최고관리자 추가 → 대표님 로그인·비밀번호 변경 → 개발사 계정 삭제 | 대표님 → 개발사 | ☐ |
| 5 | 대표님 값 입력: 사업자 정보(`brand.config.json` business → 재배포), 간편 로그인 키 3종, AI 키(`READING_AI=live`), 보상형 광고 단위(AdMob·Ad Manager) — Railway 변수 | 대표님(개발사 보조) | ☐ |
| 6 | 실결제 1건 + 환불, 월 구독 1건 + 해지 테스트 (대표님 카드) | 대표님 | ☐ |
| 7 | 개발사 멤버 해제·임시 저장소 삭제, 무상 하자보수 1개월 시작일 기록 | 개발사 | ☐ |

> **Railway 요금제 참고**: Hobby($5/월)는 고부하 시간에 새 배포가 잠시 막힐 수 있음("Deploys have been paused"). 운영 중인 서비스는 영향 없고 배포만 늦어짐. 배포가 급하거나 안정성이 중요하면 Pro($20/월, 사용량 $20 포함)를 권장. 이 프로젝트의 실제 사용량은 월 $5 안팎.
> **서버는 1대(replica 1)로 운영** — 풀이 생성·예약 푸시·로그인 상태가 서버 메모리를 쓰므로 2대 이상이면 중복 생성·로그인 실패가 생김.

## 1. 계정·서비스 이전 표

| 항목 | 현재 소유 | 옮기는 방법 | 완료 |
|---|---|---|---|
| 소스 저장소(GitHub) | 개발사 비공개 저장소(임시) | 납품본(`npm run export:delivery`)을 대표님 GitHub 새 비공개 저장소로 올림 → 대표님이 소유 | ☐ |

| 도메인 | 대표님 | `deploy/go-live.ps1` 실행 → 화면에 나온 CNAME·TXT 를 DNS 에 입력(웹 www.도메인, 서버 api.도메인) · 루트 주소는 www 로 포워딩 | ☐ |
| 웹 결제(PayApp) | 대표님(가입 완료) | `deploy/go-live.ps1` 이 연동정보 3개를 물어서 Railway 변수에 넣음(채팅·파일에 적지 않음) → 1건 결제·환불 테스트. **월 구독 자동결제는 PayApp 정기결제**를 쓰므로 PayApp 판매자 사이트에서 정기결제(카드) 사용 가능 여부 확인 → 6,900원 1건 정기결제 등록·해지 테스트 | ☐ |
| 통신판매업 신고 | 대표님 | 신고증 번호를 사이트 하단 사업자 정보(`brand.config.json` → business)에 | ☐ |
| Google Play Console | 대표님 | 개발사 초대(관리자) → 앱 등록·상품 등록·서비스 계정 연결 — 칸별 입력값·이미지·상품 목록은 `docs/스토어등록.md`, `docs/store/` | ☐ |
| 앱 서명(업로드 키) | 대표님 | 대표님 명의로 생성 → AAB 빌드 후 키 파일·비밀번호를 대표님께 전달, 개발사 사본 삭제. Play 앱 서명(구글 보관)을 켜므로 업로드 키를 잃어도 Play Console 에서 재설정 가능 | ☐ |
| Firebase(푸시) | 대표님 | 프로젝트 생성 → 개발사 초대 → google-services.json 은 git 에 넣지 않음 | ☐ |
| AdMob · 애드센스 | 대표님 | 앱/사이트 등록 → 광고 단위 ID 를 관리자 광고 관리·변수에 | ☐ |
| 간편 로그인(구글·카카오·네이버) | 대표님 | 각 개발자 콘솔에 앱 등록 → 리다이렉트 주소 `https://api.도메인/auth/<google|kakao|naver>/callback` | ☐ |
| Anthropic(AI 풀이, 선택) | 대표님 | API 키 발급 → `deploy/go-live.ps1` 에서 입력(`READING_AI=live`). 키가 없으면 유료 풀이는 '준비 중'으로 판매가 막히고 부적·구독만 판매 (비용 `docs/비용추정.md`) | ☐ |
| Google Gemini(2세 얼굴보기) | 대표님 | aistudio.google.com 에서 API 키 발급 → `deploy/go-live.ps1` 에서 입력(`GEMINI_API_KEY`). 키가 없으면 2세 얼굴보기는 '준비 중'으로 판매가 막힘 (1건 아들·딸 2장 약 130~180원) | ☐ |
