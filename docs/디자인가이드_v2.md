## 2. 글꼴

| 용도 | 글꼴 | 굵기·크기 |
|---|---|---|
| 화면 큰 제목, 상품명, 섹션 제목, 점수 숫자 | Noto Serif KR | 900 · 21~32px · 자간 -0.03em |
| 운세 풀이 본문, 한 줄 요약, 부적 설명서 | Noto Serif KR | 500 · 16.5~18px · 줄간격 1.7~1.85 |
| 메뉴·버튼·가격·배지·설명 | Pretendard | 버튼 800 18.5px / 가격 900 17px / 설명 500 14.5~15.5px |
| 한자 모티프·탭 아이콘·부적 글자·임시 로고 | Song Myung | 400 |

- 모두 OFL(상업 무료). npm `@fontsource/noto-serif-kr`, `@fontsource/song-myung`, `pretendard` 로 설치해 번들 포함(CDN 금지).
- 한국어 명조는 파일이 크므로 사용하는 굵기(500·700·900)만 포함, `font-display: swap`.
- 굵기 차이 원칙: 같은 화면에 제목 900 / 본문 500 / 캡션 500·작은 크기 — 중간 굵기 남발 금지.

## 4. 이미지 방향
- 유료 상품 썸네일·배너: 명암 강한 어두운 이미지(밤, 보름달, 촛불, 금빛) — 도사 앱 톤.
- 무료 콘텐츠 아이콘: 한자 1자 또는 단순한 선 아이콘 — 가볍게.
- 이미지 없을 때 대체: 먹색 바탕 + 금 그라데이션 한자(命 生 運 五 財 職 業 創 試 移 契 丁未 卜 月 / 愛 緣 婚 生緣 合 戀 夫 再 片 春 逢 年).
