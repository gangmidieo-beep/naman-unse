## 3. 홈 (위→아래 순서)
1. 헤더: 날씨 / 로고(대표님 아이콘 글씨) / 로그인
2. 히어로: "천궁도사와 월하선녀가 당신의 운세를 알려드립니다" (천궁도사 = 오늘의 운세·정통사주·재물운·직장·사업운·대운·신년운세 / 월하선녀 = 애정운·연애운·결혼운·궁합·인연운)
3. 오늘의 운세 카드 → 오늘의 운세 화면
4. **중간 롤링 배너 10종** (자동 넘김 + 좌우 스와이프, 순서·종류 관리자 수정): 정통운세 / 신년운세 / 평생운세 / 재물운 / 애정운 / 직장운 / 사업운 / 토정비결 / 정통궁합 / 소원부적 — 각 배너 문구는 HWP 그대로
5. **재미로 보는 운세** (2열 가벼운 카드, 무료): 띠별 운세 · 별자리 운세 · 혈액형 운세 · 오늘의 타로 · MBTI 사주 · MZ 팩폭 사주 · 꿈 해몽
6. 나만의 운명 (천궁도사) 레어 카드 가로 스크롤
7. 나만의 인연 (월하선녀) 레어 카드 가로 스크롤
8. 나만의 부적 진입 카드
9. AdMob 배너 1개 (화면 하단)

## 4. 오늘의 운세
- 탭: 오늘 / 이번 주 ✦ / 이번 달 ✦ (이번 주·이번 달 = 프리미엄)
- "OOO님 오늘의 운세에요!" + 날짜 → 총운 별점+점수 → 한 줄 요약 → 간단 풀이
- **6항목 별점**: 일 · 금전 · 연애 · 건강 · 학업 · 시험
- 행운의 색상 · 숫자 · 방향 → 오늘의 한 마디
- [상세 풀이 보기] → **보상형 전면광고** 후 열림 (프리미엄은 광고 없음)
- (v1의 "재물·애정·직장·건강 4분야" 구조는 위 6항목으로 교체)

## 5. 유료 상품 (천궁도사 14 · 월하선녀 12) — 흐름
목록(분류 탭) → **상품 상세**(히어로·담기는 내용·이용 방법·가격·회원가) → 결제 버튼("천궁도사의 상세풀이 받기" / "나의 운명서 열어보기" / "나의 인연서 열어보기") → 생성 대기 → **"천궁도사가 풀어드린 나의 운명서" / "월하선녀가 풀어드린 인연서"** 결과 화면 → 운세함 자동 보관
- 궁합 3종(정통·연인·부부)은 두 사람 정보 입력.

## 6. 나만의 부적 (14종)
목록(재물·성공 / 사랑·인연 / 소원·성취 / 평안·보호) → **부적 상세**(부적 설명서 = HWP 설명 문구, 효험 3개, 사용 방법) → [나만의 ○○부적 받기 – 가격] → 결제 → **천궁도사 또는 월하선녀 등장**: "OOO님의 마음을 담아 소원부적을 작성합니다" → 부적 쓰는 연출(소원을 담는 중.. / 좋은 기운을 새기는 중.. / 부적을 완성하는 중..) → 완성: 이름·생년월일·소원이 새겨진 부적 → 나의 부적함 보관 · 휴대폰 저장 · 공유(선물하기)
- 부적 담당 캐릭터: 재물·성공·소원·평안 = 천궁도사, 사랑·인연 = 월하선녀

## 7. 나의 운세함 ("개인 서재" 느낌)
"OO님, 오늘도 좋은 운이 함께 하기를 바랍니다."
| 영역 | 내용 |
|---|---|
| 내 사주정보 | 기본 프로필 + 여러 사람 등록(나·배우자·연인·자녀·부모) — 일반 2개 / 프리미엄 무제한 |
| 나의 운명서 | 천궁도사 결과 보관 — 예) "2026 재물운 · 2026.10.18 · 천궁도사 [다시 열어보기]" |
| 나의 인연서 | 월하선녀 결과 보관 |
| 나의 부적함 | 완성 부적·소원·발급일, 저장 |
| 결제 내역 | 상품명·결제일·금액·상태·영수증 |
| 알림 설정 | 오늘의 운세 알림 시간, 이벤트 알림 ON/OFF |
| 설정 | 로그인 계정, 약관·개인정보처리방침, 문의, 로그아웃, 탈퇴 |
