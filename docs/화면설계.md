## 2. 사용자 흐름

### 무료 (계약서: 오늘의 운세 → 총운+한 줄 풀이 → 재물·애정·직장·건강)
```
첫 실행 S0 → (예시 운세 먼저 보여줌) S2 홈 "예시" 배지
  → "내 정보 입력하면 나만의 운세로 바뀌어요" → S1 입력 → S2 홈(개인화)
  → S3 오늘의 운세 → S4 분야 상세 → (하단) 레어 카드 1개 "더 깊이 보기"
```
- 홈 첫 화면: 결제 권유 문구·가격 표시 **없음** (요구사항 확인서 4번). 프리미엄 섹션은 스크롤 아래쪽에 "레어 카드" 형태로만.
- 로그인 없이 기기 ID(게스트)로 바로 이용. 구매 시점에만 구글 계정(앱)/간편 로그인(웹) 연결.

### 유료 (계약서: 상담 → 선택 → 결제 → 풀이)
```
S6 상담: 캐릭터 인사 → "어떤 고민?" 칩(돈·재물 / 일·직장 / 연애·결혼 / 평생 흐름 / 올해 운)
      → 캐릭터가 맞는 상품 추천(레어 카드 강조) → 상품 선택
S7 결제 → 결제 완료 → S8 풀이 생성 중(캐릭터 대기 애니메이션, 30~90초) → 풀이 결과
```

## 4. 오늘의 운세 생성 방식 (AI 호출 없음 — 요구사항 약속)
1. 만세력 엔진으로 사용자 원국(4주·오행·십신) + 오늘 일진 계산.
2. 일간 × 오늘 일진의 십신 관계(10) × 12운성(12) × 합충형(있음/없음) → 규칙표로 분야별 점수(1~5) 산출. 같은 날·같은 사람은 항상 같은 결과(시드 = 날짜+프로필ID).
3. `content/today/` 문구 DB(분야별 × 점수별 × 십신별 문장 풀)에서 조합. **문장 수 최소**: 분야 4 × 점수 5 × 변형 12 = 240문장 + 한 줄 총운 120 + 조언 150.
4. 이번 주/이번 달도 같은 방식(주: 주간 일진 평균, 달: 월건).
5. 문구는 자정사주·비밀신당 문장 재사용 금지. 월하선녀 해요체.

## 5. 유료 풀이 (AI)
- 상품: 정통사주(평생·재물·직장 장 구성) / 궁합(2인) / 신년운세(12개월).
- 서버에서 엔진 계산값 + 상품별 프롬프트 → Claude API(대표님 키) → 장별 JSON → DB 저장 → 화면 렌더.
- 결과는 앱 안에서 바로 열람(메일 발송 없음), 이미지 저장·링크 공유 무료.
- 1차 시안에서는 `mock` 모드: 미리 만든 예시 풀이 JSON 을 보여준다(API 비용 0).

## 6. 관리자 (A1)
