# 나만의 운세 — 디자인 가이드 (v1, 2026-09-29)

> 기준 시안: `docs/시안/시안_v1.html` (브라우저로 열기, 긴 화면은 주소 뒤에 `#long`)
> 이 문서의 토큰 값은 시안 HTML `:root` 와 **완전히 같아야 한다.** 바꿀 땐 둘 다 바꾼다.

## 0. 대표님 요청 → 디자인 결정 대조표

| 대표님 요청 (카톡·계약서) | 어떻게 반영하나 |
|---|---|
| 도사 앱·운세보감 앱 구성 참고 | 홈 = **도사** 구조(로고 헤더, 섹션 머리말, 가로 스크롤 카드, 알림 받기 카드, 하단 탭) / 오늘의 운세 = **운세보감** 구조(오늘·이번 주·이번 달 탭, 점수+별, 분야별 별점, 행운 색·숫자·방향, 전체 풀이 버튼) |
| 전체적으로 밝은 아이보리, 깔끔 | 배경 `#FBF7EE` + 아주 옅은 점 무늬, 카드는 흰색. 도사 앱의 어두운 사진 카드는 **유료 카드에만** 사용 → 무겁지 않게 |
| 무료 = 일반 카드 | 흰 카드 + 얇은 베이지 테두리 + 네이비 "매일 무료" 배지 |
| 유료 = 금색 레어 카드 | 금색 그라데이션 3px 테두리 + "✦ 프리미엄" 금 배지 + 은은한 반짝임 애니메이션 + 캐릭터 일러스트 배경 |
| 캐릭터는 신비로운 느낌 | 천궁도령(네이비·금 별자리) / 월하선녀(분홍·라벤더·붉은 실). 보름달·금빛 성좌 원을 공통 모티프로 |
| 주 이용층 40~60대 (계약서 3조) | 본문 18px, 최소 16px, 버튼 높이 58px, 탭 아이콘 24px+글자 14px, 대비 4.5:1 이상 |

## 1. 색 (CSS 변수 이름 그대로 사용)

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#FBF7EE` | 앱 배경 (아이보리) |
| `--bg-dot` | `#EFE4CC` | 배경 점 무늬 (18px 간격) |
| `--surface` | `#FFFFFF` | 카드 |
| `--line` | `#EDE3CF` | 테두리·구분선 |
| `--ink` | `#2A2320` | 본문 글자 |
| `--ink-2` | `#5E554C` | 보조 글자 |
| `--ink-3` | `#8C8278` | 설명·캡션 (16px 이상에서만) |
| `--gold` | `#C9A24A` | 섹션 머리선, 강조 |
| `--gold-deep` | `#9E7420` | 금색 글자(흰 배경 위 대비 확보용) |

| `--gold-grad` | `linear-gradient(135deg,#FBEFC4 0%,#E2BC5E 38%,#B8862A 70%,#F0D68A 100%)` | 레어 카드 테두리, 결제 버튼, 활성 탭 |
| `--navy` | `#1E2748` | 천궁도령 색, 주 버튼, 무료 배지 |
| `--navy-2` | `#2C3766` | 네이비 보조 |
| `--purple` | `#4B3A7C` | 점수 숫자, 선택 탭 |
| `--lavender` | `#EEE8F7` | 한 줄 풀이 배경 |
| `--rose` | `#C2577A` | 월하선녀 색, 애정 |
| `--rose-soft` | `#FBE9EF` | 애정 옅은 배경 |
| `--seal` | `#B23A2E` | 로고 낙관(붉은 도장) |

규칙
- 금색은 **유료·강조에만**. 무료 화면에 금 그라데이션 금지(레어 느낌이 사라짐).
- 한 화면에 진한 배경(네이비·사진) 면적은 30% 이하.
- 분야 색: 재물=금 `#9E7420`, 애정=로즈 `#C2577A`, 직장=네이비 `#2C3766`, 건강=초록 `#3E7D5A`.

## 2. 글꼴

| 용도 | 글꼴 | 라이선스 | 비고 |
|---|---|---|---|
| 본문·UI | **Pretendard** | OFL (상업 무료) | npm `pretendard` 로 설치해 번들에 포함 (CDN 의존 X — 앱 오프라인·양도 대비) |
| 캐릭터 말풍선·한 줄 풀이 | **Gowun Batang** | OFL | 풀이 느낌 나는 명조 |
| 로고·한자(띠 한자, 부적) | **Song Myung** | OFL | 로고 글자는 최종적으로 SVG 로 변환해 고정 |

모든 글꼴은 `web/public/fonts/` 에 파일로 넣는다(woff2). 라이선스 전문을 `LICENSES/fonts/` 에 동봉 → 양도 시 문제 없음.

## 3. 글자 크기 (40~60대 기준)

| 토큰 | px | 쓰임 |
|---|---|---|
| `--fs-hero` | 28 | 화면 큰 제목 |
| `--fs-title` | 26 | 섹션 제목 |
| `--fs-card` | 21 | 카드 제목 |
| `--fs-body` | 18 | 본문 기본 |
| `--fs-small` | 16 | 설명 (이보다 작게 금지) |
| 캡션 예외 | 13~14 | 배지·탭 라벨·영문 머리말만 허용 |

- 줄간격 1.6, 풀이 본문은 1.8.
- 설정 화면에 **글자 크게 보기(보통/크게/아주 크게 = 100/115/130%)** 스위치 → `html{font-size}` 배율로 처리.

## 4. 간격·모양

- 화면 좌우 여백 18px, 카드 사이 12px, 섹션 사이 30px.
- 모서리: 큰 카드 22px, 보통 카드 20px, 버튼 16px, 배지·칩 999px.
- 그림자 하나만: `0 6px 18px rgba(80,60,20,.08)`. 레어 카드만 `0 10px 22px rgba(158,116,32,.28)`.
- 터치 영역 최소 48×48px, 주 버튼 높이 58px.

## 5. 컴포넌트 명세

### 5-1. 헤더 (홈)
좌: 음력 날짜 알약(`🌙 음 8.18`) / 가운데: 로고(붉은 낙관 `運` + "나만의 운세") / 우: `내 정보` 알약. 하위 화면은 `‹ 제목` 형태.

### 5-2. 섹션 머리말 (도사 앱 형식)
왼쪽 금색 4px 세로선 + 영문 소제목(13px, 자간 3px, `--gold-deep`) + 큰 제목 26px(강조 단어만 금색) + 회색 설명 16px.

### 5-3. 무료 카드 `FreeCard`
흰 배경, `--line` 1px, 반경 20px, 좌상단 네이비 배지 "매일 무료", 아이콘(일러스트 64px), 제목 21px, 설명 15~16px. 2열 그리드.

### 5-4. 유료 레어 카드 `RareCard`
- 바깥 3px 금 그라데이션 → 안쪽 캐릭터/상품 일러스트 + 아래쪽 어두운 그라데이션 + 흰 제목.
- 좌상단 "✦ 프리미엄" 금 배지. 반짝임: 3.6초 주기 사선 광택 (`prefers-reduced-motion` 이면 끔).
- 가로 스크롤(220×300) 또는 목록형 `RareListItem`(64px 썸네일 + 제목 + 설명 + 가격).
- 이미 구매한 상품은 배지를 "✓ 보유중"(초록)으로.

### 5-5. 오늘 인사 카드 `GreetingCard`
월하선녀 얼굴(64px 원, 로즈 테두리) + "홍길동님, 오늘의 운세가 도착했어요" + 점수(44px 보라 숫자) + 별 + 한 줄 풀이(라벤더 박스, Gowun Batang) + 네이비 버튼. **홈 첫 화면에서는 결제 유도 문구 금지.**

### 5-6. 캐릭터 말풍선 `CharacterBubble`
왼쪽 얼굴 원 + 흰 말풍선(좌상단 모서리만 4px) + 이름 라벨(선녀=로즈, 도령=네이비). 사용자 답은 오른쪽 네이비 말풍선. 선택지는 칩(`Chip`, 테두리 네이비, 선택 시 채움).

### 5-7. 오늘의 운세 패널 (운세보감 구성)
탭(오늘/이번 주/이번 달 — 이번 달은 ✦ 프리미엄) → 날짜·일진 → 점수·별 → 분야 4줄(이름 20px + 한 줄 설명 + 별) → 행운 색·숫자·방향 3칸 → AdMob 배너 자리 → 공유 버튼 → 레어 카드 1개(더 깊이 보기).

### 5-8. 하단 탭 (5개)
홈 / 오늘운세 / 사주상담 / 띠별운세 / 내 정보. 활성 탭은 금 그라데이션 둥근 사각형(52×36) + 진한 글씨. (도사는 6개지만 40~60대 기준으로 5개로 줄임)

### 5-9. 버튼
- 주 버튼: 네이비 채움 (무료 흐름)
- 결제 버튼: 금 그라데이션 + 짙은 갈색 글씨 `#3A2A08` (유료 흐름에서만)
- 보조: 흰 배경 + 테두리
- 모두 높이 58px, 글자 20px 굵게

## 6. 캐릭터 사용 규칙

| 캐릭터 | 담당 화면 | 말투 | 색 |
|---|---|---|---|
| 천궁도령 | 정통사주, 재물운, 직장운, 신년운세, 부적 | 점잖은 하오체 ("~하시게", "~구려", "~이오") | 네이비·금 |
| 월하선녀 | 오늘의 운세, 애정운, 궁합, 띠별·MBTI | 다정한 해요체 ("~해요", "~일 거예요") | 분홍·라벤더 |

- 원본: `assets/characters/천궁도령.png`, `월하선녀.png` (1024×1536). 앱용 파생 이미지는 `web/public/img/char/` 에 크기별 webp 로 만든다: 얼굴 원(240), 배너 상반신(800×547), 카드 세로(640×960).
- 캐릭터 저작권은 대표님 소유(계약서 11조 3항). 원본을 변형(크롭·색보정)만 하고 새 캐릭터를 임의로 만들지 않는다.

## 7. 모션
- 화면 전환 200ms 페이드+살짝 위로. 레어 카드 광택 3.6s. 점수 숫자 0→87 카운트업 600ms.
- `prefers-reduced-motion` 시 전부 끔.
