# 엔진 검증 — 사람이 외부 만세력과 대조할 목록

골든 테스트(36건)는 원본 엔진과 1건도 다르지 않음을 자동 확인한다. 아래 5건은 **외부 만세력으로 사람이 한 번 교차 확인**한다.

확인할 곳 (둘 중 하나):
- 한국천문연구원 음양력 변환: https://astro.kasi.re.kr/life/pageView/8
- 포스텔러 만세력: https://pro.forceteller.com/profile/edit  (또는 검색 "만세력 무료")

| # | 입력 | 우리 엔진 결과 (연 월 일 시) | 확인 포인트 |
|---|---|---|---|
| 1 | 양력 1968-03-15 07:00 남 (예시 인물) | 무신 을묘 갑신 무진 | 기본 |
| 2 | 양력 2025-02-03 22:10 | 갑진 정축 계묘 계해 | 입춘(23:10) 직전 → 아직 갑진년 |
| 3 | 양력 2025-02-04 00:10 | 을사 무인 갑진 갑자 | 입춘 직후 → 을사년 인월 |
| 4 | 음력 1972-12-29 21:00 여 | 양력 1973-02-02 · 임자 계축 기사 을해 | 음력 12월 변환 |
| 5 | 음력 2020 윤4월 15일 09:00 | 양력 2020-06-06 · 경자 임오 경진 신사 | 윤달 변환 |

참고: 이 엔진은 서머타임·출생지 경도 보정을 하지 않는다(결정필요 D9). 외부 만세력이 "경도 보정"을 켜 두면 시주가 다를 수 있으니 끄고 비교.
