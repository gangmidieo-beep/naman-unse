# 장용민 대표님 9/30 오후 브리핑 — 카톡 초안

대표님, 말씀 주신 방향으로 디자인을 다시 잡아 2차 시안 보내드립니다 😊

✅ 반영한 부분
1. 배경은 한지 느낌 아이보리로 유지하고, 먹색·골드를 메인으로 대비를 강하게 했습니다. 흰 카드와 연한 색은 모두 뺐습니다.
2. 제목과 풀이 본문은 고급스러운 명조체로, 메뉴·버튼·가격은 깔끔한 고딕으로 굵기 차이를 분명하게 나눴습니다.
3. 유료 상품은 먹색+금테 레어 카드, 띠별·별자리 같은 무료 콘텐츠는 가벼운 한지 카드로 구분했습니다.
4. 주신 화면구성 문서대로 하단 메뉴를 [홈 / 나만의 운명 / 나만의 인연 / 나만의 부적 / 나의 운세함]으로 바꾸고, 상품·가격·문구를 모두 반영했습니다.
5. 상품을 누르면 도사 앱처럼 상세 화면(담기는 내용·이용 방법·회원가)이 나오고, "천궁도사의 상세풀이 받기" 버튼으로 이어집니다.
6. 부적은 종류별 목록 → 부적 설명서·효험·사용 방법 → "나만의 재물부적 받기" 버튼 순서로 넣었습니다.
7. 천궁도사로 이름 맞췄습니다.

🖼 캐릭터는 대표님이 새로 주신 이미지로 교체 중이고, 상품 썸네일도 명암 있는 이미지로 채우는 중입니다. (지금 시안의 한자 칸은 이미지 들어갈 자리예요)
