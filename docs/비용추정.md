# 유료 풀이 AI 비용·시간 (2026-10-13 개정 — A4 40~50장 정통 감정서)

> AI 는 서버 변수 `READING_AI=live` + `ANTHROPIC_API_KEY`(대표님 키) + `ANTHROPIC_MODEL`(기본 claude-sonnet-5-5)이 있어야 켜져요. 키가 없으면 유료 풀이는 '준비 중'으로 판매가 막혀요.
> 단가 기준: Claude Sonnet 5.5 입력 100만 토큰당 **$2**, 출력 100만 토큰당 **$10**, 1달러 1,400원 (https://platform.claude.com/docs/en/about-claude/pricing). 다른 모델을 쓰면 `AI_PRICE_IN_PER_M`·`AI_PRICE_OUT_PER_M` 에 단가를 넣으면 관리자 원가가 그 값으로 계산돼요.

| 항목 | 값 |
|---|---|
| 분량 | 상품마다 본문 약 4.5만~6만 자 + 정통 분석표 → **A4 약 43~49장** (PDF 기준) |
| 구성 | 공통 명식 10장 + 상품별 부(영역·대운 8개·세운 10년·월운 12달·개운) — 장 30~50개 |
| AI 호출 | 4천 자 안팎으로 묶어 **13~19번**, 서버 전체 동시 6번(`READING_CONCURRENCY`) |
| 토큰 | 입력 약 8만~12만 · 출력 약 5만~7만 |
| **건당 원가** | 약 **1,000~1,800원** (판매가 9,900~29,000원의 약 4~10%) |
| 작성 시간 | 약 **3~6분** (화면에 "N/M장 작성" 진행률 표시, 닫아도 운세함에 보관) |
| 실패 시 | 끝난 장은 저장하고 3분 뒤 남은 장만 자동으로 다시 씀(최대 3번) |

- 분량 조절: `READING_LEN_SCALE`(기본 1.0, 0.9 면 10% 짧게·1.1 이면 10% 길게). 예전 9장 방식으로 되돌리려면 `READING_LONG=off`.
- 손금·관상(사진) AI 1건 약 30~50원, 2세 얼굴(Gemini) 1건 약 130~180원.
- 무료 콘텐츠(오늘의 운세·띠별·타로·꿈해몽 등)는 AI 를 쓰지 않아 0원.

## 켜는 순서 (대표님)
1. Anthropic 콘솔(https://console.anthropic.com/settings/keys)에서 결제수단 등록 후 API 키 발급
2. PC 에서 `deploy\go-live.ps1` 실행 → 키 입력(채팅·파일에 적지 않음)
3. 관리자 화면에서 테스트 주문 1건 → 감정서 품질·원가·PDF 확인 → 관리자에서 환불
4. 문제가 있으면 `READING_AI` 변수를 지우면 즉시 판매가 '준비 중'으로 멈춤
