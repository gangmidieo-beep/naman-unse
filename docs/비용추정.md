## 켜는 순서 (대표님 승인 후)
1. 대표님 Anthropic 콘솔에서 API 키 발급 → Railway 서버 변수 `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`

3. 문제가 있으면 `READING_AI` 를 지우면 즉시 예시 풀이로 돌아감
