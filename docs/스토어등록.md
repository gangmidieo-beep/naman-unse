> 대표님 명의 Play Console 계정에서 진행합니다. 개발사는 **사용자 및 권한**으로 초대받아 대신 설정할 수 있습니다.

## 5. 서버와 연결 (결제 확인용)

| 단계 | 할 일 |
|---|---|
| 1 | Google Cloud 콘솔(https://console.cloud.google.com) → 프로젝트 만들기 → **Google Play Android Developer API** 사용 설정 |
| 2 | IAM → 서비스 계정 만들기 → 키(JSON) 만들기 → 파일 보관(채팅·메일로 보내지 않기) |
| 3 | Play Console → 사용자 및 권한 → 서비스 계정 이메일 초대 → 권한: **재무 데이터 보기, 주문 및 구독 관리** |
| 4 | Railway 서버 변수: `GOOGLE_PLAY_PACKAGE_NAME=com.namanunse.app`, `GOOGLE_SERVICE_ACCOUNT_JSON_BASE64=`(JSON 파일을 base64 로 바꾼 값 — PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("키.json"))`) |
| 5 | (구독 갱신·해지 알림) Pub/Sub 주제 만들기 → Play Console 수익 창출 설정에 주제 연결 → 푸시 구독 주소 `https://api.도메인/billing/google/rtdn`, 인증 사용 → 그 대상(audience)을 서버 변수 `RTDN_PUBSUB_AUDIENCE` 에 |

## 6. 앱 파일(AAB) 만들기와 출시 순서

1. 업로드 키(처음 한 번): `npm run app:key -- "대표자 영문 이름" "영문 상호"` → 키 파일·비밀번호 메모를 대표님이 보관
2. 정식 서버 주소로 빌드: `MOCK_MODE=false`, `API_ORIGIN=https://api.도메인`, `PUBLIC_WEB_ORIGIN=https://www.도메인`, `ADMOB_APP_ID`·`VITE_ADMOB_BANNER_ID`(대표님 AdMob), 메모의 `NAMAN_*` 변수 → `npm run app:bundle`
3. Play Console → 테스트 → **비공개 테스트** 트랙에 `app-release.aab` 업로드 → 테스터 이메일 등록(개인 계정은 12명 이상, 14일)
4. 테스터 휴대폰에서 실제 결제 1건(테스트 카드 계정 등록 시 실제 청구 없음: 설정 → 라이선스 테스트) → 관리자 화면에서 확인
5. 조건을 채우면 **프로덕션 액세스 신청** → 심사(보통 며칠) → 출시
6. 업데이트할 때마다 `NAMAN_VERSION_CODE` 를 1씩 올려서 다시 빌드
