화면 흐름
- 무료: 오늘의 운세 → 총운 + 한 줄 풀이 → 재물·애정·직장·건강 (+ 띠별 운세 바로 찾기, 첫 화면에서는 결제 권유 없음)
- 유료: 상담 → 선택 → 결제 → 풀이
- 무료 운세를 본 뒤 더 궁금한 사람이 자연스럽게 유료로 넘어가도록 무료 공개 범위를 설계
