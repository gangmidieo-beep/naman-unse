> 대표님 피드백 전부(9/28 HWP, 9/30 오전 디자인 피드백, 9/30 오후 추가 요청 1~9)를 합친 구조. 명령어 17번의 기준 문서. 디자인 톤은 docs/디자인가이드_v2.md(한지+먹색+금) 유지.

## 1. 하단 탭 (5개) — 레이아웃은 도사 앱 기준
| 탭 | 안에 들어가는 것 |
|---|---|
| 홈 | 헤더(로고·날씨·로그인) → 오늘의 운세 카드 → **롤링 배너**(자동+스와이프, 관리자 편집) → 재미로 보는 운세(2열 가벼운 카드) → 인기 상품 가로 스크롤 → 타로 진입 배너 → 부적 진입 배너 → 알림 받기 카드 → (광고 슬롯) |
| 운세 | 상단 분류 칩: **천궁도사(나만의 운명)** 나의 운명·재물과 성공·중요한 선택·올해의 운세 / **월하선녀(나만의 인연)** 나의 사랑·두 사람의 인연·다시 이어지는 인연·새로운 만남·올해의 애정운 / **재미로 보는** 띠별·별자리·혈액형·MBTI·팩폭·꿈해몽·스몰사주·한줄사주 / **사진으로 보는** 손금·관상 → 썸네일 카드 목록 |
| 타로 | 독립 공간, **먹색·보라·금 + 밤하늘** 고급·신비 톤. 오늘의 타로(무료) / 주제별 타로(연애·재물·일·재회) / 스프레드(3장·켈틱) / 타로 안내 캐릭터 / 내 타로 기록 |
| 부적 | 분류 4개(재물·성공 / 사랑·인연 / 소원·성취 / 평안·보호) → 썸네일 카드 → 부적 상세(설명서·효험·사용법) → 구매 → 캐릭터 작성 연출 → 부적함 |
| 운세함 | 내 사주정보(여러 명) · 나의 운명서 · 나의 인연서 · 타로 기록 · 부적함 · 결제 내역 · 구독 · 알림 · 설정 |

※ "운세" 탭 = 운명+인연+재미+사진 통합은 추천안(대표님 확인 대기, 결정필요 D12)

## 2. 공통 틀 (한 번 만들고 모든 상품에 재사용)
| 틀 | 구성 |
|---|---|
| **상품 카드** | 썸네일 이미지 + 상품명 + 한 줄 설명 + 정가·할인율·판매가 + BEST/HOT/인기/NEW 배지 (전부 관리자 데이터). 목록형/그리드형 두 모드 |
| **상품 상세** | 히어로 이미지 → 상품명·한 줄 → "이런 분께 필요해요" → "지금 봐야 하는 이유" → 담기는 내용(이미지 아이콘 3~4개) → 이용 방법 → 하단 고정: 가격·회원가 + 버튼("나의 운명서 열어보기"/"상세풀이 받기"/"나의 인연서 열어보기") |
| **결과 화면** | "천궁도사가 풀어드린 나의 운명서" / "월하선녀가 풀어드린 인연서" → 장별 풀이 → **맨 아래 관련 부적 추천 카드**(상품↔부적 매핑표) → 저장·공유 |
| **무료 결과** | 가벼운 카드 결과 → 보상형 광고(프리미엄 제외) → 공유 카드 |
| **사진 분석**(손금·관상) | 촬영 가이드 → 사진 동의 → 업로드 → AI 분석 → 결과 → 사진 즉시 삭제 |

→ 상품이 늘어나도 **데이터(상품 목록·문구·이미지)만 추가**하면 되는 구조.

## 3. 데이터 구조 (관리자에서 전부 수정)
- `categories`: 탭 → 분류 → 순서
- `products`: id, 탭, 분류, 캐릭터, 상품명, 한 줄, 썸네일, 정가, 할인율, 배지, 상세(대상·이유·담기는 내용), 버튼 문구, 결과 제목, 추천 부적 id, 노출/순서
- `banners`: 홈 롤링 배너(이미지·문구·연결 화면·기간·순서)
- `talismans`: 부적 14종(설명서·효험·사용법·가격)
- `talisman_map`: 상품 → 추천 부적
- `ad_slots`: 위치별 ON/OFF, 앱=AdMob / 웹=애드센스, 프리미엄 제외

## 4. 광고
- 앱: AdMob (배너·네이티브·보상형·종료 팝업) / 웹: 애드센스 / **앱 WebView 안 애드센스 금지**
- 프리미엄 회원: 앱·웹 모두 광고 없음 (서버 권한 기준)

## 5. 캐릭터
