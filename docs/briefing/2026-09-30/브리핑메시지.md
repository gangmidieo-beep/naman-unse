대표님 안녕하세요! 「나만의 운세」 1차 시안 공유드립니다 😊
그림만 그린 시안이 아니라, 실제로 눌러서 끝까지 움직이는 화면으로 만들었습니다.

1️⃣ 전체 톤
- 밝은 아이보리 바탕에 깔끔하게, 어두운 색은 유료 카드에만 써서 무겁지 않게 했습니다.
- 40~60대 분들 보시기 편하게 본문 글씨를 크게 했고, "내 정보 › 글자 크기"에서 크게·아주 크게로 더 키울 수 있습니다.

2️⃣ 무료 / 유료 카드
- 무료(오늘의 운세·띠별·이번 주·MBTI) = 흰색 일반 카드 + "매일 무료" 배지
- 유료(정통사주·궁합·신년운세) = 금색 테두리 + ✦프리미엄 배지가 반짝이는 레어 카드
- 산 풀이는 배지가 "✓ 보유중"으로 바뀝니다.

3️⃣ 캐릭터
- 천궁도령: 정통사주·재물·직장·신년운세 안내 (점잖은 말투 "~하시게")
- 월하선녀: 오늘의 운세·애정·궁합·띠별 안내 (다정한 말투 "~해요")
- 사주상담 화면 위쪽에서 두 캐릭터를 바꿔 가며 상담할 수 있습니다.

4️⃣ 흐름
- 첫 실행: 소개 3장 → 로그인 없이 바로 "홍길동님(예시)" 운세를 먼저 보여 드리고, "내 정보 입력하면 나만의 운세로 바뀌어요"로 안내합니다.
- 정보 입력: 월하선녀가 한 번에 하나씩 묻는 대화형 (이름 → 성별 → 생년월일 → 양력/음력·윤달 → 태어난 시간/모름)
- 무료: 첫 화면에 결제 권유 없이 오늘의 운세 → 총점·한 줄 → 재물·애정·직장·건강 (+ 띠별 운세, 이번 주)
  · 분야 상세는 첫 문단까지 무료, 나머지 풀이와 오늘의 조언 3가지는 프리미엄
  · 이번 달 운세는 프리미엄
- 유료: 도령/선녀와 상담 → 고민 고르기 → 추천 풀이 선택 → 결제 → 앱 안에서 바로 풀이 확인·이미지 저장·링크 공유
- 오늘의 운세는 AI를 쓰지 않고 만세력 계산 + 새로 쓴 문장(약 950개)으로 만들어서, 같은 날 같은 분은 늘 같은 결과가 나옵니다.
