# 06. 이미지 적용

```
명령어/06 단계. web/public/img/_incoming/ 에 사람이 넣은 이미지를 앱에 적용한다. 파일명 규칙은 docs/이미지프롬프트.md 표 그대로.

1. scripts/make-images.mjs 확장(sharp): _incoming 의 파일을 용도별로 변환해 web/public/img/ 아래에 저장.
   - banner_*: 800w·1200w webp (16:9), card_*: 440×600·660×900 webp, icon_*: 128·256 webp(투명 유지), logo_seal: 64·128 png+webp, app_icon: Android 규격 mipmap 전 크기(10 단계에서 사용) + 512 스토어용, feature_graphic: 1024×500 jpg.
   - 원본은 _incoming 에 그대로 두고 git 에는 변환본만 커밋(원본은 .gitignore 에 추가하지 말고 docs/assets-source/ 로 옮겨 보관 — 양도 시 원본도 넘겨야 함).
2. 없는 파일은 자동 대체: 배너=캐릭터 원본 크롭 + 네이비 그라데이션, 아이콘=이모지 대신 단색 SVG 아이콘(직접 그린 간단한 SVG: 해·띠 원·달력·나침반·복주머니·하트·붓·찻잔), 신년운세 카드=네이비 그라데이션 + Song Myung 한자 "丙午" (시안 방식).
3. 이미지 목록 manifest(web/src/assets/images.ts)로 관리 — 컴포넌트는 manifest 키로만 이미지를 부른다(나중에 교체 쉬움).
4. 모든 img 에 width/height, loading="lazy"(첫 화면 제외), alt 한글.
5. 이미지 총용량 확인(첫 화면 1.5MB 이하).
6. 커밋 "feat(web): 이미지 적용". 어떤 파일이 들어왔고 어떤 게 대체됐는지 표로 3줄 보고 후 명령어/07 로 계속.
```
