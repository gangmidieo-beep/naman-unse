# 02. 뼈대와 엔진 (독립 모듈화)

```
명령어/02 단계. CLAUDE.md, docs/독립양도구조.md, docs/reference분석.md 를 기준으로 진행해. 묻지 말고 끝까지.

[1. 모노레포 뼈대]
- 루트 package.json: npm workspaces = ["packages/*","server","web"] (app 은 10단계에서 추가). Node 22 이상 engines 명시.
- 폴더: packages/engine, packages/content, server, web, scripts, LICENSES, docs 는 유지.
- TypeScript 공통 tsconfig.base.json, ESLint·Prettier 최소 설정, vitest.
- brand.config.json 생성 — 서비스명 "나만의 운세", 영문 slug "naman-unse", 색 토큰(docs/디자인가이드.md 1장 값 그대로), 캐릭터 2명(id, 이름, 담당, 말투, 색), 상품 목록(id·이름·설명·예시가격·담당캐릭터·googleProductId 자리), 구독(id·예시가격·혜택). 가격은 "예시"라는 플래그 isSample:true.
- .env.example: docs/독립양도구조.md 의 환경변수 목록 전부. MOCK_MODE=true 기본.
- 루트 스크립트: dev(서버+웹 동시), build, test, check:independence, make:images, db:migrate, admin:create (없는 건 빈 껍데기라도 만들어 두고 나중에 채움).

[2. 만세력 엔진 이식 → packages/engine]
- reference 에서 고른 엔진을 **복사해서** 옮긴다(reference 원본 수정 금지). TypeScript 로 감싸되 계산 로직은 바꾸지 마.
- 외부 의존 제거: DB·네트워크·환경변수·로깅 서비스 의존을 전부 걷어내고 순수 함수로. 음력·절기 데이터 파일은 packages/engine/data 로 같이 복사.
- 공개 API 를 이 형태로 정리 (index.ts):
  - calcSaju({ year, month, day, hour?, minute?, calendar:'solar'|'lunar', leapMonth?:boolean, gender:'M'|'F', timeUnknown?:boolean }) → { pillars:{year,month,day,hour|null}, elements:{wood,fire,earth,metal,water}, tenGods, twelveStages, daewoon[], dayMaster, zodiacAnimal, lunarDate }
  - dailyPillar(date) → 오늘 일진(간지), weeklyPillars(startDate), monthlyPillar(date)
  - relation(sajuResult, targetPillar) → { tenGod, twelveStage, clashes[], combines[], punishments[] }
  - zodiacOf(year) , lunarOf(date)
- 시간 모름 처리: hour=null, 시주 관련 계산은 건너뛰고 결과에 timeUnknown:true.
- 자정 기준(야자시/조자시) 처리 방식이 원본에 있으면 그대로 유지하고 NOTICE 에 적어.
- packages/engine/NOTICE.md: "이 모듈은 수급자(을)가 본 용역 이전부터 보유한 범용 모듈로, 계약서 제11조 4항에 따라 을이 계속 사용할 수 있다. 갑은 본 서비스 운영 범위에서 사용한다."

[3. 골든 테스트]
- packages/engine/test/golden.test.ts: 기준 사주 최소 30건. 경계 케이스 반드시 포함:
  입춘 전날/당일/다음날, 절입 시각 앞뒤 1시간, 음력 윤달 생일, 23:00~01:00 출생(자시), 1900년대 초·2000년대, 시간 모름 2건, 서머타임 시행 연도(1948~1951, 1955~1960, 1987~1988) 1건씩.
- 기대값은 reference 원본 엔진을 그대로 돌려서 얻은 값으로 고정(스냅샷). 원본과 1건이라도 다르면 이식 실수 → 원인 찾아 고쳐.
- 추가로 외부 만세력과 교차검증이 필요한 5건은 docs/엔진검증.md 에 "사람이 확인할 목록"으로 적고 내할일.md 에 링크(예: https://www.manseryeok.com 류의 공개 만세력 — 정확한 주소는 검색해서 적어).

[4. 독립성 검사]
- scripts/check-independence.mjs 작성(금지 문자열 목록은 스크립트 안에 base64 로 저장 — 스크립트 자신이 걸리지 않게) — docs/독립양도구조.md 의 금지 문자열 목록으로 저장소 전체 검사 (제외: reference/, docs/, 명령어/, CLAUDE.md, 진행상황.md, 내할일.md, 결정필요.md, node_modules/, .git/, scripts/check-independence.mjs 자신). 걸리면 파일:줄 출력 후 exit 1.
- npm run check:independence 통과시켜.
- .github/workflows/ci.yml: install → test → check:independence.

[5. 마무리]

- 진행상황.md 갱신. 3줄 보고 후 명령어/03 으로 계속.
```
