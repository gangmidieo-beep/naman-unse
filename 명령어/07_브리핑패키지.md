# 07. 대표님 브리핑 패키지

```
명령어/07 단계. 장용민 대표님께 카카오톡으로 보낼 1차 시안 자료를 만든다.

1. Playwright(없으면 npx playwright install chromium)로 390×844, deviceScaleFactor 2 캡처. 스크롤 긴 화면은 fullPage. 저장 위치 docs/briefing/2026-09-30/
   01_첫실행.png, 02_정보입력.png, 03_홈_예시.png, 04_홈_내운세.png, 05_오늘의운세.png, 06_재물상세.png, 07_띠별운세.png, 08_사주상담.png, 09_결제.png, 10_풀이결과.png, 11_프리미엄.png, 12_내정보.png
2. 카톡 한 장으로 보기 좋은 합본: 3열 × 4행 그리드, 각 화면 위에 번호·제목 라벨, 아이보리 배경 → docs/briefing/2026-09-30/전체화면_합본.png (가로 2400px 이내, 10MB 이내). 추가로 "무료 흐름" 합본(1~7), "유료 흐름" 합본(8~12) 2장.
3. 디자인 포인트 1장 이미지(briefing_포인트.png): 좌측 "무료=일반 카드" 실제 카드 캡처, 우측 "유료=금색 레어 카드" 실제 카드 캡처, 아래 색 팔레트 칩과 글자 크기 예시(18px 본문), 캐릭터 2명 담당표.
4. docs/briefing/2026-09-30/브리핑메시지.md — docs/브리핑_카톡초안.md 를 바탕으로, 실제 완성된 화면에 맞게 수정. 결정필요.md 에서 대표님이 골라야 하는 것(D1 가격, D2 구독 혜택, D3 PG, D6 부적, D7 패키지명·D8 도메인)만 추려 번호 매긴 질문으로 끝에 붙여.
5. 미리보기 배포 준비(실제 배포는 하지 마): web 을 정적 빌드(npm run build -w web)하고, MOCK_MODE 정적 사이트로 동작하는지 로컬 npx serve 로 확인. 배포 방법 2가지를 내할일.md 에 적어:
   - Railway: 새 서비스로 올리는 방법(사용자 계정, 서비스 이름 naman-unse-preview) https://railway.com/dashboard
   - Cloudflare Pages: dist 폴더 끌어다 놓기 https://dash.cloudflare.com → Workers & Pages → Create → Pages → Upload
6. 커밋 "docs: 1차 브리핑 패키지". 3줄 보고: 캡처 경로 / 대표님께 물을 것 / 남은 이상한 점.
```
