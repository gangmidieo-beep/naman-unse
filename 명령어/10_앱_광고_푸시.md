# 10. Android 앱 (Capacitor) · AdMob · 푸시 · 종료 팝업 · 공유

```
명령어/10 단계. app/ 에 Capacitor Android 프로젝트를 만든다. 대표님 계정(AdMob·Firebase·Play)이 없으면 구글 공식 테스트 광고 ID 와 mock 으로 끝까지 만들고, 키 넣는 자리를 README·내할일.md 에 정리.

[1. Capacitor]
- @capacitor/core·cli·android 최신 안정판. appId 는 결정필요 D7 결과, 미정이면 임시 "com.namanunse.app" 로 하고 결정필요.md 에 "스토어 첫 업로드 전 반드시 확정 — 이후 변경 불가" 경고.
- webDir = web/dist. 앱은 번들된 정적 파일로 동작(서버 URL 로드 방식 금지 — 심사·오프라인 대비). API 주소는 빌드 환경변수.
- 플러그인: @capacitor/app(뒤로가기), @capacitor/preferences, @capacitor/share, @capacitor/filesystem(이미지 저장), @capacitor/status-bar, @capacitor/splash-screen, @capacitor/push-notifications, @capacitor-community/admob, cordova-plugin-purchase.
- 스플래시: 아이보리 배경 + 로고. 상태바 아이보리·어두운 아이콘.
- 앱 아이콘: web/public/img 의 app_icon 변환본(없으면 임시로 로고 낙관 + 보름달 SVG 로 생성).
- Android: minSdk 24, targetSdk 최신 Play 요구치, 권한은 INTERNET·POST_NOTIFICATIONS 만.

[2. AdMob]
- 배너: 오늘의 운세·띠별·분야 상세 하단 AdSlot. 프리미엄이면 안 보임.
- 전면: 종료 팝업(아래 4)과 "광고 보고 부적 1장 더"(13 단계) 에만. 과도한 전면 광고 금지(정책).
- 개발 중엔 구글 공식 테스트 ID 사용, 운영 ID 는 환경변수. UMP(동의 메시지) 연동.

[3. 푸시 (FCM)]
- 첫 실행 후 오늘의 운세를 본 다음에 알림 권한 요청(바로 요청 금지) — 선녀 말풍선 "내일 아침에도 챙겨드릴까요?" → 허용 시 토큰 서버 등록.
- 서버 firebase-admin 으로 발송. 08 단계 push_campaigns 예약 발송 실제 연결. 매일 아침 사용자 push_time 개인화 발송(개인 점수 한 줄 넣기: "홍길동님 오늘 87점, 윗사람 한마디에 길이 보여요").
- 알림 탭 → 딥링크(/today 등) 이동.
- google-services.json 은 git 제외, 위치·받는 방법 README 에.

[4. 앱 종료 팝업]
- 안드로이드 뒤로가기로 홈에서 나갈 때: 서버 exit_popup 설정을 읽어 ① AdMob 네이티브/전면 또는 ② 이미지+링크(다른 앱 유도) 바텀시트 + [종료] [취소]. 비율(ratio) 에 따라 가끔만. 설정 없으면 단순 "종료할까요?" 시트.

[5. 공유·저장]
- 결과 카드 이미지 → Filesystem 저장(갤러리) + Share 시트. 공유 텍스트에 웹 링크(/s/:code).

[6. 빌드]
- npm run app:sync, app:open, app:build:debug 스크립트. 디버그 APK 를 app/android/app/build/outputs 에 만들고 경로를 보고.
- 릴리스 빌드용 서명 설정은 keystore 경로를 환경변수로만 받게(키스토어 파일은 절대 git 금지). 업로드 키는 대표님 명의로 생성해야 한다고 README·HANDOVER 에 명시.
- Windows 에 Android Studio/JDK 가 없으면 설치 방법과 링크를 내할일.md 에 적고(https://developer.android.com/studio), 그 전까지 가능한 것(sync, 설정)까지만 하고 다음 단계로.

[7. 마무리]
- 웹 쪽 플랫폼 분기 테스트(웹에서는 AdMob·Play 결제 코드가 로드되지 않음, 앱에서는 PG 문구 노출 없음).
- 커밋, 진행상황.md, 3줄 보고 후 명령어/11 로 계속.
```
