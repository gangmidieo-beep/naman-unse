# 04. 오늘의 운세 (AI 호출 없음) + 분야 상세 + 띠별

```
명령어/04 단계. 오늘의 운세는 요구사항상 "AI 미호출 — 엔진 계산 + 미리 작성된 문구 조합"이다. docs/화면설계.md 4장 방식대로 만든다. 묻지 말고 끝까지.

[1. 계산 규칙 — packages/content/src/today/engine.ts]
- 입력: 사용자 calcSaju 결과 + 날짜. 출력: { total:0~100, stars:1~5, oneLine, fields:{wealth,love,work,health}:{stars,summary,detail[],advice}, lucky:{color,number,direction}, dayPillar, lunarDate }.
- 점수 규칙표(rules.json)로 관리 — 코드에 숫자 박지 말 것:
  - 오늘 일진 천간이 일간에 대해 갖는 십신 10종 → 분야별 기본 가중치 (예: 정재·편재 → 재물↑, 정관·편관 → 직장↑, 식신·상관 → 애정·표현↑, 인성 → 건강·문서↑, 비겁 → 지출·경쟁 주의)
  - 일진 지지 vs 일지·연지: 육합·삼합 가점, 충·형·파·해 감점
  - 12운성(일간 기준 일진 지지) 가감
  - 용신·희신 판단이 원본 엔진에 있으면 반영, 없으면 오행 과부족으로 간이 판단
  - 총점 = 분야 가중평균을 55~96 범위로 스케일(너무 낮은 점수는 이탈 원인 — 최저 55)
- 같은 사람·같은 날짜는 항상 같은 결과(시드 = yyyymmdd + profileId 해시). 문장 선택도 시드로.
- 행운 색·숫자·방향: 부족한 오행 기준(목=초록/3·8/동, 화=빨강/2·7/남, 토=노랑/5·10/중앙→"가까운 곳", 금=흰색/4·9/서, 수=검정·남색/1·6/북).
- 이번 주 = 7일 일진 평균 + 주간 흐름 한 줄, 이번 달 = 월건 기준.
- 단위 테스트: 규칙 조합별 결과 범위, 같은 입력 동일 출력, 시간 모름 처리.

[2. 문구 DB — packages/content/data/today/*.json]
- 월하선녀 해요체, 40~60대가 읽기 쉬운 쉬운 말(한자어·전문용어 최소, 한 문장 40자 안팎). 자정사주·비밀신당 문장 재사용 금지(비슷한 문장도 금지 — reference 문구와 겹치는 8글자 이상 연속 구절을 검사하는 스크립트 scripts/check-copy-overlap.mjs 를 만들어 통과시켜).
- 분량(최소): oneLine 120문장(점수대 5 × 24), 분야 4 × 별점 5 × 요약 12 = 240, 분야 심화 문단 4 × 5 × 6 = 120, 조언 150(할 일/피할 일/한마디), 이번 주 60, 이번 달 60.
- 재물·직장 심화 문단은 천궁도령 하오체 버전을 따로 둔다(분야 상세 화면에서 도령이 말하므로).
- 금지: 공포 조장(죽음·사고·큰 병 단정), 의료·투자 단정 표현. 건강은 "무리하지 마세요" 수준.
- 문장 검수 스크립트: 길이, 금지어(사망, 이혼 확정, 파산, 암 등), 말투 어미(선녀=요, 도령=오/구려/시게) 자동 검사.

[3. 화면]
- S3 /today: 시안 ② 그대로 — SegTabs(오늘/이번 주/이번 달 ✦) → 선녀 말풍선 → 점수 패널(날짜·일진 한자·점수·별·분야 4줄) → LuckyGrid → AdSlot → 공유 버튼 → RareListItem 1개(천궁도령 정통사주). 이번 달 탭은 PremiumLock.
- S4 /today/:field: 상단에 담당 캐릭터 배너(재물·직장=도령, 애정·건강=선녀) + 별점 + 요약 + 심화 첫 문단(무료) + 나머지 문단·조언 3개(PremiumLock) + "이 분야를 평생 흐름으로 보기" 레어 카드(재물→정통사주 재물편, 애정→궁합, 직장→정통사주 직장편, 건강→신년운세).
- S5 /zodiac: 12띠 그리드 → /zodiac/:animal: 오늘 띠 운세 한 줄 + 출생연도별(예: 1964·1976·1988·2000년생) 한 줄씩. 띠 문구 DB 12 × 연도 5 × 30일 순환분 생성(규칙: 띠 지지와 오늘 일진 지지 관계 + 연도 천간). 40~60대가 많이 찾는 1956~1990년생 연도 반드시 포함.
- 공유: 웹은 Web Share API(없으면 링크 복사), 결과 카드를 이미지로 저장(html-to-image, 1080×1350, 워터마크 "나만의 운세").
- 홈 GreetingCard 를 실제 계산값으로 연결.

[4. 검증·마무리]
- 테스트 통과, 390px 캡처 3장(today, today/wealth, zodiac/horse) docs/시안/ 에 저장.
- 커밋 2개 이상(엔진 규칙 / 문구 DB / 화면). 진행상황.md 갱신. 3줄 보고 후 명령어/05 로 계속.
```
