# 99. 한방 실행 (01 → 07 연속, 브리핑용 시안까지)

> 오늘 밤 이것 하나만 붙여넣고 자면 됩니다. 내일 아침 `진행상황.md` 와 `docs/briefing/` 를 확인하세요.

```
CLAUDE.md 규칙대로, 명령어 폴더의 01_분석과계획.md → 02_뼈대와엔진.md → 03_디자인시스템과홈.md → 04_오늘의운세.md → 05_유료상담_mock.md → 06_이미지적용.md → 07_브리핑패키지.md 를 순서대로 직접 읽고, 각 파일의 코드블록 안 지시를 하나씩 끝까지 수행해.

진행 규칙:
- 나에게 묻지 마. 결정이 필요하면 결정필요.md 에 선택지와 추천안을 적고, 추천안으로 진행해.
- 한 단계가 끝날 때마다: 테스트 실행 → git commit → 진행상황.md 갱신 → 바로 다음 단계.
- 에러가 나면 원인을 찾아 고쳐. 같은 문제를 3번 시도해도 안 되면 진행상황.md 의 "막힌 것" 에 적고 다음 작업으로 넘어가.
- 외부 키·계정이 필요한 것은 mock 으로 구현하고 내할일.md 에 링크와 함께 적어.
- reference 폴더는 읽기만. 자정사주·비밀신당 키·URL·문장을 가져오지 마. 단계마다 npm run check:independence.
- 디자인은 docs/디자인가이드.md 와 docs/시안/시안_v1.html 을 벗어나지 마. 글자 16px 미만 금지(배지·탭 라벨 예외).
- 11 단계(실제 AI 호출)는 이번 실행에 포함하지 마.
- 07 까지 끝나면 최종 보고: ① 완료한 것 ② 결정한 것(추천안으로 진행한 것) ③ 내가 확인할 것 ④ 대표님께 물을 것 — 그리고 docs/briefing/2026-09-30/ 파일 목록.
```
