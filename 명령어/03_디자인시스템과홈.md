# 03. 디자인 시스템과 홈 화면

```
명령어/03 단계. 목표: docs/시안/시안_v1.html 의 ① 홈 화면을 web 앱에서 "그대로" 재현하고, 공통 컴포넌트를 만든다. 디자인은 docs/디자인가이드.md 가 법이다. 묻지 말고 끝까지.

[1. web 세팅]
- web/: Vite + React 18 + TypeScript + react-router. 상태관리는 zustand(가볍게). 서버 통신은 fetch 래퍼(src/lib/api.ts) — MOCK_MODE 면 src/mock/ 의 JSON 을 돌려줌.
- 글꼴: npm i pretendard 로 설치해 번들에 포함. Gowun Batang, Song Myung 은 woff2 를 web/public/fonts 에 넣고 @font-face (CDN 금지 — 앱 오프라인·양도 대비). OFL 라이선스 전문을 LICENSES/fonts/ 에.
- src/styles/tokens.css: 디자인가이드 1·3·4장의 CSS 변수 전부(이름 그대로). brand.config.json 의 색과 같은지 테스트로 검사.
- 글자 크게 보기: html data-scale="100|115|130" → :root font-size 배율. 모든 크기는 rem 으로.
- 모바일 우선: 최대 폭 480px 가운데 정렬, 데스크톱에서는 양옆 아이보리 배경 + 가운데 앱 화면(웹 첫 방문자도 앱처럼 보이게). 하단 탭은 480px 안에 고정.
- safe-area(노치·제스처바) padding 처리.

[2. 공통 컴포넌트 — src/components/, 각각 Storybook 대신 /dev/components 페이지 하나에 전부 나열]
AppHeader(홈형/하위형), SectionHeader(영문 소제목+금 세로선+제목 강조), FreeCard, RareCard(가로형 220×300, 광택 애니메이션, 보유중 상태), RareListItem, GreetingCard, CharacterBubble(선녀/도령/사용자), Chip·ChipGroup, ScoreStars(점수 카운트업), CategoryRow, LuckyGrid, SegTabs, TabBar(5개), Button(primary/gold/line), PremiumLock(흐림+금 테두리 안내), AdSlot(웹=자리 표시, 앱=AdMob), NoticeCard(알림 받기), ZodiacGrid, BottomSheet, Toast, Skeleton.
- prefers-reduced-motion 이면 애니메이션 끔.
- 모든 버튼·탭 최소 48px, 글자 16px 미만 금지(배지·탭 라벨 13~14px 예외).

[3. 홈 화면 S2 — 시안 ① 과 동일 배치]
헤더(음력 날짜 알약 — 엔진 lunarOf 로 실제 값 / 로고 / 내 정보) → GreetingCard(오늘 점수·한 줄은 04 단계 전까지 mock) → "매일매일 무료로 보세요" FreeCard 2×2(오늘의 운세, 띠별 운세, 이번 주 운세, MBTI 운세) → "도령과 선녀가 깊이 풀어드려요" RareCard 가로 스크롤(정통사주·우리 궁합·신년운세) → "내 띠 운세 바로 찾기" ZodiacGrid → NoticeCard(알림 받기) → TabBar.
- 사주 정보 입력 전: 운세보감 방식으로 "홍길동님(예시)" + 보라 "예시" 배지 + "내 정보를 입력하면 나만의 운세로 바뀌어요" 링크. (docs/참고화면/참고_운세화면.jpg 상단 참고)
- 홈에는 가격·결제 문구 금지.
- 캐릭터 이미지: 06 단계 전까지는 assets/characters 원본에서 scripts/make-images.mjs(sharp)로 만든 web/public/img/char/{dosa,sunnyeo}_{face,banner,card}.webp 사용. 시안의 크롭 위치(docs/시안/img) 참고. make-images 를 지금 만들어 돌려.

[4. 사주 정보 입력 S1 + 첫 실행 S0]
- S0: 3장 스와이프(1 선녀 "매일 아침 오늘의 운세를 챙겨드려요" / 2 도령 "정통 사주로 평생 흐름을 풀어드리지요" / 3 "로그인 없이 바로 시작") → 시작하기.
- S1: 월하선녀 말풍선으로 한 칸씩 묻는 대화형 입력(이름 → 성별 → 생년월일(큰 휠 피커 또는 8자리 숫자 입력 둘 다) → 양력/음력(음력이면 윤달 체크) → 태어난 시간(12지시 버튼 + "모름")). 한 화면에 질문 하나, 글자 크게. 마지막에 요약 확인 카드 → 저장.
- 저장: MOCK_MODE 면 localStorage + zustand persist, 서버 연결 후 08 단계에서 동기화. 프로필 여러 개(가족) 저장 가능하게 구조만 잡기.

[5. 검증]
- Playwright(없으면 npx playwright install chromium)로 390×844 에서 홈 캡처 → docs/시안/비교_홈.png. 시안_v1.html 캡처와 나란히 놓고 차이를 스스로 비교해 5가지 이상 다르면 고쳐.
- 콘솔 에러 0, 가로 스크롤 0.
- 커밋: "feat(web): 디자인 토큰·공통 컴포넌트·홈·입력 화면". 진행상황.md 갱신. 3줄 보고 후 명령어/04 로 계속.
```
