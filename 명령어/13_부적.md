# 13. 한자 부적 생성 (계약서: 주제별 설명 글에 맞춘 한자 부적 이미지 → 저장·공유)

```
명령어/13 단계. AI 이미지 생성이 아니라 "코드로 그리는" 부적(SVG → PNG)으로 만든다(비용 0, 품질 일정, 저작권 문제 없음).
1. 주제 8종: 재물·합격·건강·애정·사업번창·가정화목·이사/새출발·액막이. content/data/talisman/*.json 에 주제별: 제목, 설명 글(천궁도령 하오체 4~6문장), 한자 문구(예: 재물=招財進寶, 합격=金榜題名, 건강=無病長壽, 애정=百年佳約 등 — 전통 길상어 중심, 의미 해설 포함), 색 조합, 문양.
2. 렌더러 web/src/features/talisman/render.ts: 세로 2:3 노란 한지 질감(SVG 필터 노이즈) + 붉은 테두리 문양 + Song Myung 세로쓰기 한자 + 붉은 낙관(사용자 이름 첫 글자 또는 運) + 하단 작은 글씨로 이름·생년·발급일. 주제별 레이아웃 3변형, 사용자 사주 부족 오행에 따라 보조 문양(목=대나무, 화=해, 토=산, 금=동전, 수=물결) 추가.
3. 흐름(/talisman): 도령 말풍선 "어떤 기운이 필요하오?" → 주제 선택 → 설명 글 → [부적 받기] → 붓 그리는 애니메이션(1.5초) → 완성 → [갤러리 저장] [공유] [배경화면용(9:16) 저장].
4. 무료/유료는 결정필요 D6 결과대로 설정값(brand.config.talisman.freePerDay, needAd, premiumUnlimited) 로 구현. 기본안: 하루 1장 무료(광고 시청 후), 프리미엄 무제한.
5. 안내 문구: "재미와 마음가짐을 위한 콘텐츠예요" 작게 표기.
6. 테스트(8주제 × 3변형 렌더 스냅샷) · 커밋 · 진행상황.md · 3줄 보고 후 명령어/14 로 계속.
```
