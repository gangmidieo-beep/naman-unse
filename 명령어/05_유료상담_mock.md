# 05. 유료 흐름 (상담 → 선택 → 결제 mock → 풀이) + 프리미엄 + 내 정보

```
명령어/05 단계. 실제 결제·AI 는 아직 연결하지 않는다(MOCK_MODE). 화면과 흐름을 완성해서 브리핑에서 "눌러보면 끝까지 가는" 상태로 만든다. 묻지 말고 끝까지.

[1. S6 사주상담 /consult — 시안 ③ 그대로]
- 상단 히어로 배너: 캐릭터 전환 토글(천궁도령 ↔ 월하선녀). 도령=정통사주·재물·직장·신년운세, 선녀=궁합·애정.
- 대화형: 캐릭터 인사 → 고민 칩(돈·재물 / 일·직장 / 연애·결혼 / 평생 흐름 / 올해 운) → 캐릭터 답 한마디 + 추천 상품 1개를 선택 상태로 강조 + 나머지 상품 RareListItem → 금색 결제 버튼("✦ 9,900원 결제하고 풀이 받기").
- 상담 대사는 packages/content/data/consult.json 에(고민별 3변형, 캐릭터 말투 지키기).
- 가격은 brand.config.json 에서 읽고 isSample 이면 옆에 작게 "예시 가격".
- 프리미엄 회원이면 버튼 문구 "프리미엄 할인가 ○원" (할인율은 brand.config — 결정필요 D2).

[2. S7 결제 /checkout/:product]
- 주문 요약(상품·대상 프로필·가격) → 결제수단(앱=Google Play 한 가지, 웹=PG 수단 목록) → 약관 동의 체크 → 결제.
- src/platform/payments.ts 인터페이스: purchase(productId, profileId) → { status:'paid'|'cancelled'|'failed', orderId }. 구현체: mock(1.5초 후 paid), web-pg(09 단계), google-play(10 단계).
- 이벤트 추적 훅 자리(product_view, checkout_open, pay_start, pay_success, pay_cancel, pay_fail) — 지금은 console + localStorage 로그, 08 단계에서 서버 전송.

[3. S8 풀이 결과 /reading/:orderId]
- 생성 대기 화면: 도령이 별자리 판을 읽는 애니메이션(loading_dosa 이미지 없으면 CSS 별 회전) + "별을 읽고 있소… (약 1분)" + 단계 표시(원국 계산 → 흐름 읽기 → 글 정리).
- 결과: 표지(캐릭터 + 상품명 + 이름·생년월일·원국 8글자 한자 표) → 목차 → 장별 카드(제목, 캐릭터 한마디, 본문 18px/줄간격 1.8, 핵심 문장 금색 형광 밑줄) → 마무리 조언 → [이미지로 저장] [링크 공유] [다른 풀이 보기].
- mock 데이터: packages/content/data/sample-readings/{saju,gunghap,newyear}.json — 실제 상품처럼 장 6~10개, 각 장 400~700자. 도령 하오체/선녀 해요체로 새로 작성(자정사주 문장 금지). 예시 인물 "홍길동, 1968년 양력 3월 15일 오전 7시, 남"의 실제 엔진 계산 결과를 표지에 사용.
- 결과는 앱 안에서 바로 열람. 메일 발송 없음. 저장·공유 무료.

[4. S9 프리미엄 /premium]
- 두 캐릭터 함께 있는 배너 + 혜택 비교표(무료 vs 프리미엄: 광고, 이번 달 운세, 분야 심화, MBTI 연결, 단건 할인) — docs/화면설계.md 3장 표 그대로 + 월 구독 버튼(금색) + "언제든 구글 플레이에서 해지할 수 있어요" 안내 + 구매 복원 링크.

[5. S10 내 정보 /me]
- 내 사주 프로필(여러 명, 추가·수정·삭제, 대표 프로필 선택) / 구매한 풀이 목록 / 구독 상태 / 글자 크기(보통·크게·아주 크게) / 알림 시간(기본 오전 7시) / 구매 복원 / 공지 / 약관·개인정보처리방침·사업자 정보(자리만, 값은 대표님 정보 오면) / 문의(카카오 채널 링크 자리) / 버전.

[6. MBTI·부적 자리]
- 홈 FreeCard 의 MBTI 운세, RareCard 목록 끝의 부적은 "준비 중이에요 — 곧 열려요" 바텀시트(12·13 단계에서 교체).

[7. 검증·마무리]
- Playwright 시나리오 테스트: 첫 실행 → 입력 → 홈 → 오늘의 운세 → 상담 → 상품 선택 → 결제(mock) → 대기 → 결과 → 이미지 저장 버튼까지 에러 없이 통과.
- 커밋. 진행상황.md 갱신. 3줄 보고 후 명령어/06 으로 계속.
```
