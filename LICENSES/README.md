
## 타로 카드 그림 (web/public/img/tarot)
- 1909년 라이더-웨이트-스미스(Rider-Waite-Smith) 원판, 그림 Pamela Colman Smith — 미국·한국 모두 저작권 보호기간이 끝난 퍼블릭 도메인
- 원본 스캔: Wikimedia Commons "Rider-Waite tarot deck (Roses & Lilies)" (퍼블릭 도메인 표시)
- U.S. Games 의 "Universal Waite"(1990년 재채색판)는 저작권 덱이라 쓰지 않음
